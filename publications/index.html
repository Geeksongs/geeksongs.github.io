  2. Preprint
    Simulation for Evaluating Robot Policies Should Be Asynchronous and Real-Time
    Python Song, Hyeonho Oh, Ishika Singh, Jesse Thomason, Ajay Mandlekar, and Siddharth Ancha
    IEEE International Conference on Robotics and Automation (ICRA), 2026
    Abs PDF Video Code Website

    Current robot simulation benchmarks run policies synchronously, giving unlimited thinking time per step – unrealistic for real-world deployment. We introduce AsyncRoboSim, which runs the policy and simulator in parallel processes communicating through shared observation/action queues, while the simulator keeps advancing in real time. This better reflects real inference latency and improves correlation between simulation and real-world performance.
